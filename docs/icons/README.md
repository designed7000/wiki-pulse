# Diagram icons

Logos used in `docs/architecture.d2`, kept here so the diagram renders without network access.

- `kafka`, `airflow`, `postgresql`, `python`, `fastapi`, `react`: [Devicon](https://github.com/devicons/devicon) v2.17.0, MIT licence.
  `python.svg` has its drop shadow removed and its gradients moved into `<defs>`, which D2's SVG importer requires.
- `wikipedia`: [Simple Icons](https://github.com/simple-icons/simple-icons) 13.21.0, CC0.

The logos are trademarks of their owners and are used here only to identify the technology.
